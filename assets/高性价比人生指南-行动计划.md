# 高性价比人生指南 · 行动计划

> 依据：eternity4719《高性价比人生指南》（498 条建议，193 页）提炼本 →
> 见同目录《高性价比人生指南-提炼.md》
> 本计划只做两件事：**按性价比排出执行顺序**、**给每条一个可打勾的验收动作**。
> 这是对一本书的整理，不是医疗或法律意见；具体用药、诊断、诉讼请找医生和律师。

---

## 0. 先看这一段（30 秒版）

这本书的排序规则是「成本接近零、收益大的放最前面」。所以执行顺序**不按重要性排，按每份投入的回报排**：

```
第 1 层：今天就能做完的开关动作（0 元 / ≤30 分钟 / 证据 A）   ← 做完就有大部分收益
第 2 层：这周的一次性投入（0–500 元 / 一次）                  ← 装上、查一次、打一针
第 3 层：这个月建立的习惯与替换（0 元 / 靠替换不靠加钱）
第 4 层：这个季度的手续与契约（法律、证件、职业）
第 5 层：每年固定的年历动作
第 6 层：触发式预案（出事那一刻才用，但要提前准备）
```

**只做第 1、2 层，就能拿到全书收益的大头。** 第 3 层最难（要毅力），可以放慢，但不做前面的白做。

## 1. 今天（0 元、30 分钟内、全部证据 A）

一次性做完，全部打勾。

### 1.1 安全开关（5 分钟）

- [ ] **系安全带**：确立规则「上车就系，前排后排都系」——轿车前排致死伤害风险降 45%，轻型卡车降 60%
- [ ] **电动自行车**：确认「不推进楼道、不进电梯、不在家充电」——个人罚 500–1000 元，但真正的代价是它堵住唯一的逃生通道
- [ ] **骑车戴头盔并把扣子扣好**：死亡风险降 42%，头部损伤降 69%；挂在车把上不算戴
- [ ] **喝了酒不碰方向盘**，包括电动车和「挪一下车」

### 1.2 手机与账号（10 分钟）

- [ ] **关掉非必要通知**，工作时手机放到视线之外
- [ ] **邮箱、支付、社交账号全开二次验证**，优先用手机弹窗确认，其次才是短信验证码
- [ ] **邮箱用单独密码**，不和任何网站重复
- [ ] **手机设锁屏密码，SIM 卡设 PIN 码**
- [ ] **关掉所有自动续费**，改为到期手动续
- [ ] **把 12356（心理援助）、96110（反诈）、12308（境外领保）存进通讯录**

### 1.3 饮食与身体（10 分钟，多数要下次买菜时执行）

- [ ] **下次买盐换成低钠盐**（钾盐）——两万人随机试验：五年内死亡概率低约 12%，中风低约 14%
- [ ] **家里不再进含糖饮料**，换白水或无糖茶
- [ ] **停掉槟榔**
- [ ] **定一个固定的起床时间**，周末也一样

### 1.4 一条底线规则（5 分钟）

- [ ] 写下并记住：**「所有要我先转钱、先交费、共享屏幕的，一律挂断」**
- [ ] 再加一条：**涉及转账，挂断后用自己通讯录里的旧号码打回去核实**——视频里的脸、电话里的声音都不算核实

## 2. 这周（0–500 元，一次性装上 / 查一次 / 打一针）

### 2.1 家里装上（约 200–400 元）

- [ ] **装烟雾报警器**：住宅火灾死亡风险降约六成（四成起火时人在睡觉，靠鼻子醒不过来）
- [ ] **冬天在室内烧煤/用燃气的，加装一氧化碳报警器**：中国 2018 年 1.15 万人死于一氧化碳中毒，冬季三个月七成死在家里
- [ ] **看燃气软管和灶具到没到期**，到期就换；不上门推销的当（条例第 20 条禁止燃气公司指定产品）
- [ ] **备齐灭火器、灭火毯、逃生呼吸面罩、急救包**（一套几百元）
- [ ] **有小孩的装窗户和阳台限位器**——纱窗不算防护

### 2.2 查一次（合计约 300–800 元，多数几十到一两百）

- [ ] **量血压**（买电子血压计 100–200 元）：血压每降 10 mmHg，主要心血管事件降两成、中风降 27%、死亡降 13%；中国 35–75 岁 44.7% 有高血压，控制住的只有 7.2%
- [ ] **35 岁以后超重就查空腹血糖**（十几元），正常也每三年再查
- [ ] **查乙肝两对半**，没抗体就补三针（共 100–300 元）
- [ ] **查幽门螺杆菌**（呼气试验 100–200 元），阳性就根除
- [ ] **有过高危行为就去疾控查一次**（免费、可匿名）

### 2.3 按年龄/性别安排筛查（本月内预约即可）

- [ ] 女性 **30 岁以上**做宫颈癌筛查，优先 HPV 检测（阴性可 5 年一次）
- [ ] 女性 **40 岁起**每两年一次乳腺钼靶（很多地区有免费项目）
- [ ] **45–50 岁起**做结直肠癌筛查（粪便检测 1–2 年一次，或肠镜阴性可 10 年一次）
- [ ] **重度吸烟者**每年一次低剂量胸部 CT
- [ ] **50 岁以后**带状疱疹疫苗；**65 岁以上**肺炎球菌疫苗；**每年秋天**流感疫苗
- [ ] **女性尽早接种 HPV 疫苗**

### 2.4 牙齿

- [ ] 预约**洗牙**，并开始**每天清一次牙缝**（牙线/牙缝刷），缺牙补上

### 2.5 计划类（各 5 分钟）

- [ ] 挑 1–2 件一直在「打算做」的事，写成**「几点、在哪、遇到什么就做什么」**
- [ ] 给一个没有外部截止的事**自己定一个日期**
- [ ] 给任何一个在手的大项目**写下退出条件**（到某日期没达到某指标就停）

## 3. 这个月（建立习惯与替换，0 元为主）

**这一层不靠加钱，靠替换。** 顺序按原书章节性价比排。

### 3.1 动（最便宜的一档，证据 A）

- [ ] **每天走到 7000–8000 步**（可拆进通勤和买菜）
- [ ] **每周累计 150–300 分钟中等强度运动**（快走即可）
- [ ] **每周 30–60 分钟力量训练**（徒手深蹲、俯卧撑不花钱）
- [ ] **把爬楼梯、快走赶路这类零碎用力攒到每天四五分钟**
- [ ] **别连着坐太久**，设个提醒，隔一阵起身
- [ ] 有条件的话**每周三次球拍类运动**（场地费每次几十元）

### 3.2 吃（全部是替换，不是增加）

- [ ] 少吃**加工肉**（火腿、培根、香肠、午餐肉）
- [ ] 把一部分**红肉换成鱼和禽肉**
- [ ] 把一部分**精米白面换成全谷物**
- [ ] 每天**一小把坚果**（28 克，一年约两三百元）
- [ ] 每天**5 份（约 400 g）水果蔬菜**
- [ ] 每周**三次以上茶**；每天**三到四杯咖啡，不加糖不加奶盖**
- [ ] **不喝甜味饮料，无糖的也算**
- [ ] 少吃**超加工食品**；不喝**滚烫**的茶汤咖啡，放一放再喝

### 3.3 睡与精力

- [ ] **每晚睡 7 小时左右，作息固定**
- [ ] **下午两点以后不碰咖啡因**
- [ ] **睡前一小时不看发光屏幕**（看纸书或墨水屏）
- [ ] **到点就睡**，手机不进卧室
- [ ] **一次只做一件事**，不开会回消息
- [ ] 做需要连续思考的活时，**把哪怕几秒钟的打断也挡在外面**（关门、耳机、勿扰牌）
- [ ] **邮件和消息改成每天固定几次批量处理**
- [ ] **下午困了睡 10 分钟，不要睡半小时**
- [ ] **深夜不做重大决定、不发要紧的消息**

### 3.4 心理与情绪（证据 A 的那几条）

- [ ] **心情差就去走或跑**（抗抑郁效应量与强度成正比）
- [ ] 焦虑影响生活时，**用正念减压课**（效果不劣于常用抗焦虑药）
- [ ] 当场想缓过来，用 **5 分钟「循环叹息」**：吸气两段，呼气拉长
- [ ] **把「定期和人见面」当成健康支出**，别只在心情差时才找人
- [ ] 住得离绿地近就多用它
- [ ] 发现自己**反复回想同一件糟心事**时，换个需要动手的活
- [ ] 把**「事情肯定会更糟」这类念头当症状看，不当事实看**

### 3.5 体重与烟酒

- [ ] **BMI 控制在 20–25**（原书标注：毅力成本最大的一条）
- [ ] **戒烟**（金钱是负成本：一天一包 20–30 元，戒了就省下）
- [ ] **别在家里和车里抽烟**，也别让客人在家里抽
- [ ] **少喝或不喝酒**

## 4. 这个月（要花一次钱或跑一趟的账）

### 4.1 钱（把本该领回的领回来）

- [ ] **医保 App 办一次家庭共济绑定**：个人账户的钱能给配偶、父母、子女看病买药
- [ ] **3 月到 6 月做一次个税汇算**，专项附加扣除该填的填
- [ ] **交个税的人开个人养老金账户**，每年 12000 元税前扣除（不交个税的人开了不划算）
- [ ] **公积金不只买房**：租房、装修、物业费都能提
- [ ] **重算手机和宽带套餐**，用不上的降档；运营商不给转就投诉
- [ ] **存出 3–6 个月生活费的应急金**，放在随时能取的地方
- [ ] **每年免费查两次自己的征信报告**，看有没有不是自己办的贷款和卡

### 4.2 少花的钱（不做清单见第 7 节）

- [ ] 贷款**不用最低还款**，不为消费开分期或消费贷
- [ ] **不借钱投资、不加杠杆、不买自己看不懂的**
- [ ] 长期底仓用**宽基指数基金**替代主动管理基金；同类优先选**费率低**的
- [ ] **别把钱押在一只股票、一个平台、一套房上**；**不频繁交易**
- [ ] **三者险买够**——交强险限额全国统一且不高，超出的从你自己家里出
- [ ] 保险优先买**消费型**，把「返还」「分红」当作不保证的部分
- [ ] 一年期医疗险/重疾险**看清「保证续保」四个字**
- [ ] **提前还房贷之前先做一道比较题**，不要凭感觉
- [ ] 健身房**按次或短周期付费**，除非有一年以上稳定记录
- [ ] **交预付款要签书面合同**；商家出风险要停收，跑路前有权要回未消费余额
- [ ] 大额非必需购买设 **24 小时冷静期**；不为「划线价」和大促囤货
- [ ] 买大件前查**国家抽检通报、3C 认证、能效标识**

### 4.3 医疗合规动作

- [ ] 慢病到社区**办门诊慢特病认定**，再办**异地备案**（高血压、糖尿病、放化疗、透析、抗排异可异地直接结算）
- [ ] 稳定期慢病**回社区开 12 周长处方**，别拿三级医院当开药点
- [ ] 常见病**先在社区看**，需要时经基层**逐级转诊**（同一统筹区级别越低报销比例越高，差约 10 个百分点）
- [ ] 每次看完病**把病历、检查报告、影像自己存一份**

## 5. 这个季度（手续、契约、职业）

### 5.1 法律与证件（按你家的情况挑）

- [ ] **有老人**：趁老人清醒，书面指定将来的监护人；把遗嘱立了（后立的推翻先立的，公证遗嘱不再优先）
- [ ] **有老人**：老人的钱单独放一个账户，大额支出定一个双人确认的规矩
- [ ] **有老人**：长期卧床或重度失能的，去参保地医保部门申请**长期护理保险**
- [ ] **治完确实留下功能障碍**：去户籍地县级残联申请**残疾人证**（伤残鉴定要等治疗终结后再做，做早了等级会评低）
- [ ] **房产/婚姻**：父母出资买房，转账时就把**是借是送**写清楚；婚前财产、加名先写清楚
- [ ] **借款**：写清借条；替人担保前先想清楚愿不愿意替他还；**不签空白纸、不替人签字**
- [ ] 记住三条时效：**民事诉讼 3 年、劳动仲裁 1 年**——过了对方一句「超过时效」就够

### 5.2 职业与收入（在职的人）

- [ ] **存下工资条、考勤、劳动合同、社保记录、聊天记录**
- [ ] **不要让公司把离职写成「个人原因主动辞职」**——那一签就没有 N 了
- [ ] 算一遍自己的 **N 与 2N**：每满一年一个月工资，不满六个月按半个月；公司没提前 30 天通知再多付一个月；违法解除是二倍
- [ ] **有过粉尘、噪声、化学品岗位的**：确认三次职业健康检查由单位安排并掏钱；没有防护措施的作业可以拒绝
- [ ] **上班受伤/上下班路上被撞**：第一件事是做**工伤认定**，单位不报你自己报
- [ ] 签了竞业协议的：离职后公司**不按月给补偿就书面催告，满 3 个月没给可以解除**

### 5.3 员工/收入不确定时的兜底（先领国家给的）

- [ ] 失业了**先在线申领失业保险金**，同时办失业登记、争取就业困难人员认定
- [ ] 被欠薪**先投诉劳动监察，再申请劳动仲裁**，两条路都不收费
- [ ] 打不起官司**申请法律援助**（讨薪、赡养费、工伤本来就在范围内）
- [ ] **居民医保每年 400 元不要断**，困难户可减免
- [ ] 得了重病**先走医保、大病保险、医疗救助和异地备案，不碰网贷**
- [ ] 走投无路**去救助站**（管吃住和返乡车票）；收入低于当地低保线**申请低保**
- [ ] **不交押金、不押证件、不签「培训贷」、不进传销、不借高利贷**

### 5.4 如果你写代码

- [ ] 动手前先问三句：**损害了谁的利益、对方多有能力追究、我留了多少证据**
- [ ] 自查：不做外挂、不写抢票/秒杀/刷单脚本、爬虫只爬无需登录的公开页面、不接赌博/诈骗/色情单
- [ ] 离职时**交清账号权限，不删库、不留后门**；不带走源码、客户名单和技术文档
- [ ] **自己的开源项目用自己的时间和设备做**，不混公司代码
- [ ] 网站、App 上线前先做 **ICP 备案**，按等级保护要求**留存 6 个月以上日志**
- [ ] 对公众提供生成式 AI 服务前，先做**安全评估和算法备案**，生成内容加标识

### 5.5 如果你要开公司/做平台

- [ ] **只拿亏得起的钱创业**，不动家底、不借钱开张；**不给公司贷款签个人担保**（配偶更不要跟着签）
- [ ] 开张前**选对主体**：个体户和合伙人赔到底，有限公司才「有限」
- [ ] 加盟前**查商务部备案**，拿到书面披露，把「冷静期」写进合同
- [ ] 领了执照就开始有申报义务，**没有收入也要按期零申报**
- [ ] 收钱写**「定金」不写「订金」**，违约金写明数，账期当放贷来审
- [ ] 用人**第一个月内签书面合同，30 日内办社保登记**
- [ ] 平台**不要自己收钱再转给卖家**，让钱走持牌支付机构直接结算
- [ ] 有人上来卖东西：**核验登记、报送信息、留存三年**；用户内容要有审核机制和举报入口
- [ ] 亏了就**按程序退场**：能简易注销就注销，资不抵债走破产，别放着不管

## 6. 每年固定动作（写进年历）

| 时间 | 动作 |
| --- | --- |
| **3–6 月** | 个税汇算，专项附加扣除该填的填 |
| **9–11 月** | 流感疫苗 |
| **每年 2 次** | 免费查征信报告（看有没有不是自己办的贷款和卡） |
| **每年 1 次** | 家庭应急装备检查（灭火器、报警器电池、急救包、逃生面罩） |
| **每年 1 次** | 重算手机和宽带套餐；清理账号登录设备与已授权应用 |
| **按各自间隔** | 血压（常测）、血糖（超重后每 3 年）、宫颈癌筛查、钼靶（每 2 年）、肠癌筛查、低剂量 CT（重度吸烟者） |
| **每年 1 次** | 车险/三者险检视，三者险保额够不够 |
| **每年 1 次** | 社保参保状态与缴费连续性检查 |

## 7. 不做清单（Negative List）——省下的就是赚到的

**健康类**

- 不为长寿或防心血管病吃**复合维生素**、**普通鱼油**
- 不为防癌吃**抗氧化补剂**（β 胡萝卜素、维生素 E、维生素 A）
- 不为长寿给**不缺维生素 D 的人**补 D
- 不指望**氨糖/软骨素**治膝关节炎；不靠**维生素 C** 预防感冒
- 不给没有症状的自己买**全身 PET-CT** 或**肿瘤标志物套餐**
- 不指望**手环/手表**的运动量化帮你减重
- 不为「更健康」花溢价买**有机食品**
- 没有肠道问题**不长期吃益生菌**；不为了「增强免疫力」逼自己**洗冷水澡**
- 不买**排毒、清肠、酵素、碱性水**这类产品
