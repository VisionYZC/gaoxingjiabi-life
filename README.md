# 《高性价比人生指南》· 阅读站

把 **eternity4719** 的《高性价比人生指南》（193 页 PDF，498 条建议，31 节）整理成一个可检索、可打勾的静态站点。

- `index.html` —— 核心观点：四种资源、性价比口径、证据分布、31 节地图
- `book.html` —— 原书全库：498 条建议，支持关键词搜索与证据/成本维度筛选，每条可展开「证据 · 来源 · 备注」
- `plan.html` —— 行动计划：今天 / 这周 / 这个月 / 这个季度 / 每年 / 触发式预案 六层打勾清单

构建方式：`python build_site.py`（`--scope=core` 生成精简版）。纯静态、无依赖、无外部 JS，勾选状态只存在浏览器本地。

本次构建模式：`full`。

> 本站是对一本书的结构化整理，不是医疗或法律意见。证据等级 A/B/C 为原书自定分级，本站照录。
